# livehermoment.com — 배포 가이드

폴더 안 파일 전부(`index.html`, `CNAME`, 로고·파비콘 png, `robots.txt`, `sitemap.xml`)를 그대로 올리면 됩니다. 서버도, 빌드도 필요 없어요.

---

## 1단계 — 미리 보기 (맥북에서)

`index.html`을 더블클릭하면 크롬에서 바로 열립니다. 여기서 먼저 확인하세요.

## 2단계 — GitHub에 올리기

1. github.com → 우측 상단 `+` → **New repository**
2. Repository name: `livehermoment` / **Public** 선택 / 나머지는 그대로 → **Create repository**
3. 다음 화면에서 **uploading an existing file** 링크 클릭
4. 이 폴더의 **파일 7개를 전부 드래그**해서 올림 (폴더째로 말고 파일만)
5. 아래 **Commit changes** 버튼 클릭

## 3단계 — GitHub Pages 켜기

1. 저장소 상단 **Settings** → 왼쪽 메뉴 **Pages**
2. Source: **Deploy from a branch**, Branch: **main** / **/(root)** → **Save**
3. 1~2분 뒤 새로고침하면 주소가 뜹니다. `CNAME` 파일 덕분에 Custom domain 칸에 `livehermoment.com`이 자동으로 채워져 있을 거예요. (비어 있으면 직접 입력 후 Save)

## 4단계 — 가비아에서 도메인 연결

가비아 → My가비아 → 도메인 → `livehermoment.com` → **DNS 정보 → DNS 관리**

아래 레코드를 **추가**합니다.

| 타입 | 호스트 | 값 | TTL |
|---|---|---|---|
| A | @ | 185.199.108.153 | 3600 |
| A | @ | 185.199.109.153 | 3600 |
| A | @ | 185.199.110.153 | 3600 |
| A | @ | 185.199.111.153 | 3600 |
| CNAME | www | `본인깃허브아이디.github.io.` | 3600 |

> ⚠️ **MX 레코드는 절대 건드리지 마세요.** 네이버웍스 메일(kate@livehermoment.com)이 그 레코드로 돌아갑니다. A/CNAME만 추가하면 메일에는 영향이 없습니다.

DNS 반영은 보통 10분~1시간, 길면 하루까지 걸립니다.

## 5단계 — HTTPS 켜기

DNS가 반영되면 Settings → Pages에 **Enforce HTTPS** 체크박스가 활성화됩니다. 체크하면 자물쇠(https://) 완료. (체크박스가 회색이면 아직 DNS 반영 전이니 조금 기다렸다 다시 오세요.)

## 나중에 내용 수정하려면

`index.html` 하나만 고치면 됩니다. 텍스트는 이런 형태로 들어 있어요.

```html
<h3 data-ko="퍼포먼스 마케팅" data-en="Performance marketing">퍼포먼스 마케팅</h3>
```

- `data-ko` = 한국어 버전, `data-en` = 영어 버전 (우측 상단 EN 버튼으로 전환)
- **태그 사이의 글자와 `data-ko` 값, 두 군데를 똑같이 고쳐야 합니다**
- 줄바꿈은 `|` 기호로 넣습니다 (예: `data-ko="첫 줄|둘째 줄"`)

마켓(시계) 목록은 `<script>` 안 `MARKETS` 배열에서 추가·삭제할 수 있습니다.

수정한 `index.html`은 GitHub 저장소에서 파일 클릭 → 연필 아이콘 → 수정 → Commit 하면 1분 안에 사이트에 반영됩니다.

# SEO — 검색에 잡히게 만들기

파일 안의 태그 작업은 끝났습니다. 아래는 **직접 등록해야 하는** 작업이에요. 이걸 안 하면 검색엔진이 사이트 존재 자체를 모릅니다.

## 1. 구글 서치콘솔 등록 (필수, 10분)

1. [search.google.com/search-console](https://search.google.com/search-console) 접속 → **속성 추가**
2. 왼쪽 **도메인** 방식 선택 → `livehermoment.com` 입력
3. 화면에 뜨는 **TXT 레코드 값**을 복사
4. 가비아 DNS 관리에서 추가: 타입 `TXT` / 호스트 `@` / 값 `붙여넣기` / TTL `3600`
5. 서치콘솔로 돌아와 **확인** 클릭 (DNS 반영에 10분~1시간)
6. 확인되면 좌측 메뉴 **Sitemaps** → `sitemap.xml` 입력 → 제출

> MX 레코드는 여기서도 건드리지 않습니다. TXT는 여러 개 공존할 수 있어요.

## 2. 네이버 서치어드바이저 등록 (한국 검색용, 필수)

한국에서 회사명을 검색하는 사람은 대부분 네이버를 씁니다. 구글만 하면 절반을 놓쳐요.

1. [searchadvisor.naver.com](https://searchadvisor.naver.com) → 웹마스터 도구 → **사이트 등록**
2. `https://livehermoment.com` 입력
3. 소유확인 방법에서 **HTML 태그** 선택 → 나오는 `<meta name="naver-site-verification" ...>` 한 줄 복사
4. `index.html`의 `<title>` 바로 아래에 그 줄을 붙여넣고 GitHub에 커밋
5. 네이버에서 **소유확인** 클릭
6. 확인되면 **요청 → 사이트맵 제출**에 `https://livehermoment.com/sitemap.xml` 입력

## 3. 빙 웹마스터 (선택, 3분)

[bing.com/webmasters](https://www.bing.com/webmasters) 에서 **구글 서치콘솔에서 가져오기**를 누르면 자동으로 끝납니다. ChatGPT 검색이 빙 인덱스를 쓰기 때문에 해두면 좋아요.

## 이미 적용해 둔 것

| 항목 | 내용 |

| 이미지 alt | 모든 이미지에 설명 텍스트. 로고 alt에 회사 소개 문구 포함 |

| 404.html | 잘못된 주소로 들어와도 브랜드 페이지가 뜨도록 |

## 앞으로 순위를 올리려면

지금은 한 페이지짜리라 걸 수 있는 검색어가 회사명 정도입니다. 검색 유입을 늘리려면 **내용이 있는 페이지 수**가 늘어야 해요. 순서대로 효과가 큽니다.

1. **회사명 검색 선점** — 등록만 끝내면 1~2주 내 "livehermoment", "라이브허모먼트"로 1위 확보
2. **사업 소개 페이지 분리** — `/marketing`, `/commerce` 처럼 페이지를 나누면 "크로스보더 셀러", "쇼피 대행" 같은 검색어를 노릴 수 있음
3. **글 쌓기** — 쇼피 운영이나 동남아 마켓 관련 실전 글은 경쟁이 적어서 잘 잡힙니다
4. **외부 링크** — 링크드인 회사 페이지, 사업자 디렉토리 등에 도메인을 걸어두면 신뢰도가 올라감

2번이 필요해지면 말씀해주세요. 지금 구조에서 페이지 추가하는 건 어렵지 않습니다.

## 통신판매업 신고, 지금 해야 하나?

일반적인 기준은 이렇습니다. 다만 확정 판단은 관할 구청 또는 세무 담당자에게 확인하세요.

- **국내 소비자에게 온라인 판매를 하면** 신고 대상입니다.
- **해외 플랫폼에서 해외 소비자에게만 판매하는 경우**는 국내 통신판매로 보지 않아 신고 대상이 아니라고 보는 것이 일반적입니다.
- 직전 연도 통신판매 **거래 횟수 50회 미만**이면 면제 규정이 있습니다.
- 신고는 정부24에서 온라인으로 가능하고, 등록면허세(연 약 4만 원대)가 발생합니다.

즉 지금처럼 Shopee 해외 판매만 하는 단계라면 급하지 않습니다. **국내 판매를 시작하는 시점**에 신고하시면 됩니다.
